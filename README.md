# S&P 500 Monthly Direction Prediction — ML Pipeline

End-to-end machine learning pipeline that predicts whether an S&P 500 constituent stock will post a **positive return over the next ~20 trading days (1 month)**, using price-technical + macroeconomic features. Built as an academic thesis project.

> ⚠️ **Not financial advice.** This is a research/educational project. Backtest results are gross of transaction costs, slippage, and taxes, and come from a single out-of-sample split rather than walk-forward validation across multiple market regimes.

## Data

- **Prices:** Daily OHLCV for ~500 S&P 500 constituents (2000–2024), sourced via Hugging Face dataset + Kaggle.
- **Macro (FRED):** Real GDP (`GDPC1`), 10Y Treasury yield (`DGS10`), 10Y-2Y yield spread (`T10Y2Y`), corporate bond OAS spread (`BAMLC0A0CM`), VIX (`VIXCLS`). All resampled to daily frequency with forward-fill to avoid look-ahead on release dates.
- **Universe metadata:** S&P 500 addition dates and GICS sector, from a public sector-mapping CSV, with manual corrections for ~40 tickers with missing/renamed data.
- Final modeling dataset after feature engineering, outlier removal, and cleaning: **~2.55M stock-day rows spanning 2000-10-16 to 2024-03-11**.

## Feature Engineering

Monthly-horizon features only (daily noise dropped intentionally):

- **Momentum:** `Ret_1M`, `Ret_3M`, `Ret_6M` (20/60/120 trading-day returns)
- **Trend:** `Dist_SMA_50`, `Dist_SMA_200` (% distance from moving averages)
- **Volatility:** `ATR_Norm` (20-day ATR normalized by price), `Vol_Rel` (volume relative to 20-day average)
- **Technical:** `RSI_14`, `MACD`
- **Macro:** `US10Y`, `YieldCurve`, `CorpSpread`, `VIX`
- **Target:** `Target_Class` = 1 if 20-trading-day forward return > 0, else 0

Data cleaning applied before training: IQR-based outlier removal on returns (factor 3.0, hard-capped at ±50%/day), removal of the top 10% highest-volatility regime days, and 1st/99th percentile clipping on the target. `GDP`, `Month`, and raw OHLC price columns were dropped from the final feature set (leakage/noise risk for tree models).

## Method

- Time-series split (80/20, no shuffling) — train on earlier dates, test on the most recent ~20% of the timeline.
- Features scaled with `StandardScaler` (fit on train only).
- 4 models benchmarked head-to-head: Logistic Regression, Random Forest, XGBoost, LightGBM.
- Model selection by AUC on the held-out test set.
- Backtest: monthly-hold strategy — go long (equal-weight) on stocks where `P(up) ≥ 0.55`, compare cumulative return against an equal-weight benchmark over the same test window.

## Known Limitations

- **Single train/test split.** No walk-forward or k-fold time-series cross-validation across multiple market regimes (e.g., 2008 GFC, 2020 COVID crash). The reported backtest outperformance has not been stress-tested outside its one test window.
- **No transaction costs.** Backtest returns are gross — no slippage, commissions, or bid-ask spread. Monthly rebalancing a large stock universe in practice would to erode returns.
- **Class-imbalance-sensitive metrics.** Accuracy/precision/recall reported at a fixed threshold (0.55); no threshold-sensitivity or calibration analysis included.
- **Earlier iteration bug (fixed here):** an earlier version of this pipeline had a rolling-window bug that silently dropped ~2.6M rows, leaving only ~10 months of usable data and an AUC of ~0.51 (no signal). This version fixes that and trains on the full 24-year history.
